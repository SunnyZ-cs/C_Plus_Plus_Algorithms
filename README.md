# ⚡ C++ Algorithm & Logic Showcase

**High-Performance Recursive Algorithms, Grid Processing, and Data Structures**

This repository contains an extensive collection of robust C++ implementations of complex algorithmic challenges. It demonstrates my deep understanding of low-level memory management, efficient recursive design, spatial grid processing, and custom data structure implementations.

## 🌟 Featured Projects & Algorithms

### 1. `Advanced_Recursion`
Sophisticated algorithmic solutions utilizing complex recursion without iterative loops. Includes recursive backtracking (e.g. `MountainsOfRecursia`), string parsing and validation.

### 2. `Custom_Hash_Tables`
Implementation of a `LinearProbingHashTable` from scratch, illustrating collision handling, dynamic resizing, and efficient load-factor management.

### 3. `Dynamic_Memory_And_Pointers`
Showcases safe and leak-free dynamic memory management, including `DoublyLinkedLists` and graph processing structures like `Labyrinth` and particle systems.

### 4. `Grid_Search_And_Maps`
2D grid algorithms modeling complex traversals, such as flood-fills (`RisingTides`), graph mappings, and fire spread simulations.

### 5. `Optimization_Algorithms`
Backtracking and combinatorial optimization strategies (e.g. `ShiftScheduling`, `DisasterPlanning`) designed to prune decision trees and find optimal solutions efficiently.

### 6. `Tree_Data_Structures`
Custom implementation of a balanced binary search tree (`Treemap`), emphasizing complex pointer operations, traversals, and $O(\log n)$ efficiency.

### 7. `Audio_Processing`
Physical modeling of string instruments and audio tone matrices simulating realistic harmonic oscillation and superposition.

## 🧠 Technical Highlights
*   **Language:** C++ (Standard Template Library)
*   **Concepts:** Recursion, Memory Safety, Pointers, Linked Lists, Hash Tables, Binary Search Trees, Probabilistic Modeling.
